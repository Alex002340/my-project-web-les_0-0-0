Пасажирські платформи

для посадки та висадки

Платформи — споруди для посадки та висадки пасажирів з поїздів. Бувають низькі (до 0,5 м) та високі (до 1,1 м).

Вимоги ПТЕ: платформи мають бути безпечними, мати освітлення, інформаційні вказівники, захисні огорожі та засоби екстреного зв'язку.

Нормативні вимоги до пасажирських пристроїв

Ширина платформ

Не менше 3 м для острівних платформ та 2,5 м для берегових.

Освітлення

Не менше 10 лк для платформ та 20 лк для переходів.

Температурний режим

В залах очікування не нижче +16 °C взимку.

Вентиляція

Забезпечення повітрообміну не менше 20 м³/год на особу.

Джерело: ДБН В.2.3-19 «Пасажирські пристрої залізничного транспорту», ДБН В.2.2-15 «Доступність будинків і споруд».

Згідно з ПТЕ та екологічним законодавством

Станції залізничного транспорту є джерелами шуму, вібрації, забруднення повітря та ґрунту. ПТЕ встановлює вимоги щодо мінімізації впливу на навколишнє середовище.

Шумозахист

Шумозахисні екрани та спеціальні рейки для зменшення шуму від поїздів у житлових зонах.

Захист водних ресурсів

Поводження з відходами

Озеленення

Перевірте свої знання

7 питань для самоконтролю

1. Які пристрої належать до пасажирського господарства станції?

Правильно: б. До пасажирського господарства належать вокзали, платформи, пішохідні переходи, зали очікування, каси та інші пристрої для обслуговування пасажирів.

2. Яка мінімальна ширина острівної пасажирської платформи?

Правильно: в. Згідно з ДБН В.2.3-19, мінімальна ширина острівної платформи — 3 м, берегової — 2,5 м.

3. Для чого призначені вантажні платформи?

Правильно: б. Вантажні платформи призначені для виконання вантажних операцій — навантаження та розвантаження вантажів з вагонів.

4. Що таке пости ЕЦ?

Правильно: б. Пости електричної централізації (ЕЦ) — це приміщення з обладнанням для керування стрілками та сигналами станції. З постів ЕЦ черговий по станції керує рухом поїздів та маневровою роботою.

5. На якій відстані один від одного встановлюються пожежні гідранти?

Правильно: в. Згідно з вимогами ПТЕ та протипожежних норм, пожежні гідранти встановлюються з розрахунку не більше 150 м один від одного для забезпечення ефективного гасіння пожеж.

6. Які засоби механізації застосовуються для вантажних робіт?

Правильно: б. Для прискорення вантажних робіт застосовуються різноманітні засоби механізації: козлові та мостові крани, автонавантажувачі, конвеєри, ваги різних типів.

7. Які екологічні вимоги встановлює ПТЕ для станцій?

Правильно: б. ПТЕ встановлює комплексні екологічні вимоги: шумозахист (екрани, спеціальні рейки), очищення стічних вод від вантажних дворів та депо, сортування та утилізація відходів, захисні лісонасадження по периметру станції.
